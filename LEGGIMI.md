App web in **sola consultazione**: legge il file Excel del calendario scelto dall'app File (OneDrive). Il file viene letto solo sul telefono e non viene mai caricato online.
La cartella `sito/` contiene l'app già pronta (motore compilato, nessun sorgente). Il progetto completo è in un repository privato del titolare.

**Sull'iPhone:** apri l'indirizzo del sito con Safari › Condividi › **Aggiungi alla schermata Home**.
Per aggiornare i dati: «Aggiorna» e scegli di nuovo il file.
